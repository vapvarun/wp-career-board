# Progressive web app

Your visitors can install your job board on a phone or desktop like an app. This needs WP Career Board Pro, and there is nothing to switch on.

## What you can do

- Change the app colour under **Career Board > Settings > Brand**.
- Set a square site icon under **Settings > General > Site Icon**.

## Where to read the full guide

See the WP Career Board Pro docs, page named **PWA**.
