# AI features for employers

You can draft a job description and rank applicants by fit, when the site owner has set up AI.

## What you can do

- **Draft a description.** On the post-a-job form, click **Generate with AI**.
- **Rank applicants.** Use the ranking button on your employer dashboard.

If you do not see these controls, the site owner has not turned on AI.

See the WP Career Board Pro docs, page named **AI features**.
