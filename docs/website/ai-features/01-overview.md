# AI features overview

With WP Career Board Pro and an AI provider key, you can offer candidates plain-language job search and cover letter drafts, and give employers a job description writer and applicant ranking. The plugin works fully without AI.

## What Pro adds

- **AI Chat Search** - candidates search jobs in plain language with the AI Chat Search block.
- **Recommended jobs** - job matches for each candidate on their dashboard.
- **Applicant ranking** - employers rank applicants by fit from the employer dashboard.
- **Cover letter writer** - candidates draft a letter from the apply panel.
- **Description writer** - employers use **Generate with AI** on the post-a-job form.

## How to turn it on

1. Install and activate WP Career Board Pro.
2. Go to **Career Board > Settings > AI Settings**.
3. Choose a provider and add its key.

Without a provider, the AI controls stay hidden. The AI Chat Search block shows a notice to site owners that asks them to finish AI Settings.
