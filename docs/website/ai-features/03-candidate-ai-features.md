# AI features for candidates

You can search jobs in plain language, see recommended jobs and draft a cover letter, when the site owner has set up AI.

## What you can do

- **Search in plain language.** Use the AI Chat Search block on the page where the site owner placed it.
- **See recommended jobs.** Your candidate dashboard shows job matches when AI matching is available.
- **Draft a cover letter.** Use the generate control in the apply panel of a job.

If you do not see these controls, the site owner has not turned on AI.
