# Set up AI providers

You can connect an AI provider to switch on the AI features. Setup is done in Pro.

## Steps

1. Go to **Career Board > Settings > AI Settings**.
2. Choose a provider and enter its key.
3. Save.

Pro supports OpenAI, Anthropic Claude and Ollama (self-hosted).

## Where to read the full guide

Provider fields, models, matching setup and indexing existing jobs are covered in the WP Career Board Pro docs, on the page named **AI features**. Developers who want to add a provider can read the Pro page **AI providers and endpoints**.
